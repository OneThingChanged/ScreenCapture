# ScreenCapture v0.1.7

This release improves repeated region capture, output quality controls, and video navigation in the media library.

## Changes

- Adds a persistent adjustable frame for repeated region screenshots and recordings.
- Keeps the capture frame open after each screenshot and excludes the frame itself from captured output.
- Passes clicks through the frame interior while keeping the toolbar and resize handles interactive.
- Adds four capture-resolution presets: Compact, Balanced, High, and Original.
- Adds four recording-quality presets that control source bitrate and MP4 encoding quality.
- Adds reliable seeking to media-library video playback through HTTP-style byte-range responses.
- Adds frame-by-frame video navigation with the arrow and comma/period keys, using the source video's detected frame rate.
- Updates the English and Korean documentation for the new workflow.

## Downloads

- Use `ScreenCapture-Setup-0.1.7-x64.exe` for installation and automatic updates.
- Use `ScreenCapture-Portable-0.1.7-x64.exe` to run ScreenCapture without installation.

Windows SmartScreen may display a warning because this release is not Authenticode-signed.
